# Stash 0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the four pieces of `docs/superpowers/specs/2026-10-15-v0.3-design.md`: text in images, duplicate merging, the app in four languages (plus README and website), and a Homebrew tap.

**Architecture:** Image text and duplicates are new units in `Storage/` and `Capture/` that talk to the existing `SearchIndex` and `LibraryStore`; the UI changes are additive (a detail section, a ⌘K action, a capture line and action bar state). Localization uses `.lproj` string tables copied into the app bundle by `build-app.sh`, checked against the compiler's own list of localizable keys. The website gets a stdlib-only Python generator that writes one page per language.

**Tech Stack:** Swift 5.9, SwiftUI/AppKit, Vision, CryptoKit, GRDB (existing), Swift Testing; Python 3 (standard library) for the site; Homebrew cask DSL and GitHub Actions for the tap.

Every task ends with `swift build` (zero warnings), `swift test` (all passing) and a commit on branch `v0.3`. Nothing is pushed until the user has tested the build.
