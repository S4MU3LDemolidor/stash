# Stash 0.3: text in images, duplicates, languages, Homebrew

Approved on 2026-10-15. Four independent pieces, shipped together as v0.3.0.

## 1. Search the text inside images

Screenshots and ad creatives are mostly text. Stash reads it on the Mac and makes it searchable.

- **Recognition:** Vision's `VNRecognizeTextRequest`, accurate level, language correction on,
  automatic language detection, on-device only (no network). `ImageTextRecognizer.text(in:)`
  returns the lines joined by newlines, capped like `FileTextExtractor` (100 000 characters).
- **Storage:** index only, in the existing `fileText` column (searched with weight 1). Markdown
  files don't change, so nothing syncs and nothing conflicts. An image that was read but had no
  text gets `""`, so it isn't read again; `NULL` means "not read yet". No schema change: existing
  images have `NULL` and get picked up.
- **When:** `ImageTextIndexer` (main actor, like `Enricher`) runs after saving an image and after
  any library change, reading every image whose `fileText IS NULL`, one at a time, at utility
  priority, newest first. Images whose file isn't there (iCloud placeholder) are skipped and tried
  on the next pass.
- **Rebuilding the index** clears the text; the indexer reads the images again in the background.
- **Library:** the detail pane shows a **Text in Image** section (selectable, at most 12 lines,
  then "…"). ⌘K gets **Copy Text in Image** for images with text.

## 2. Already saved? Merge instead of duplicating

When what Capture holds is already in the library, Stash says so, and ↵ adds the new note and
tags to the existing reference instead of saving a second one.

- **Matching** (`DuplicateKey`, pure and tested):
  - Links: scheme `http`/`https` ignored, host lowercased without `www.`/`m.`, trailing `/`
    dropped, fragment dropped (kept when it's a route: `#/…`, `#!…`), query items sorted with
    tracking parameters removed (`utm_*`, `fbclid`, `gclid`, `dclid`, `msclkid`, `yclid`, `igshid`,
    `si`, `ref`, `ref_src`, `ref_url`, `mc_cid`, `mc_eid`, `_hsenc`, `_hsmi`, `mkt_tok`,
    `spm`, `share`, `feature`).
  - YouTube: same video ID, and timestamps within 2 seconds (no timestamp counts as 0). The
    same video at another moment is a new reference.
  - Text: trimmed, runs of whitespace collapsed, case-insensitive.
  - Images and files: same byte size first (cheap), then SHA-256 (CryptoKit, part of macOS).
- **Finding:** `DuplicateFinder` asks the index for candidates (links on the same host, all text
  references, images and files) and compares in the background. When several match, the newest
  wins. Images and files are only hashed when a size matches.
- **Capture:** under the card, "Already saved 3 weeks ago · #hooks #ads". The action bar becomes
  **Add to Existing ↵** and **Save Copy ⌥↵**. ⌘↵ also merges (and keeps the panel open).
- **Merging** (`LibraryStore.update`): tags are the union (existing first); a non-empty note is
  appended on a new paragraph unless the existing note already contains it; a link without a
  title takes the new one. Nothing new → no write, HUD "Already in Stash". Otherwise HUD
  "Added to the Existing Reference".
- **Saving** waits for the check (like it waits for the browser read), so a quick ↵ still merges.

## 3. Stash in Português (Brasil), Español and Français

- **Strings:** `Support/Localization/<lang>.lproj/Localizable.strings` for `en`, `pt-BR`, `es`,
  `fr`. Keys are the English text; `en` lists every key (identity), so a missing translation falls
  back to English and a language with no translation at all doesn't fall back to another one.
- **Bundle:** `build-app.sh` copies the `.lproj` folders into `Contents/Resources`; `Info.plist`
  lists `CFBundleLocalizations`. Stash follows the macOS language, and System Settings ›
  General › Language & Region › Applications can pick one just for Stash.
- **Code:** SwiftUI literals (`Text("…")`, `Button("…")`, `Toggle("…")`) localize as they are.
  Strings built in code use `String(localized:)`, including interpolations (`%@`, `%lld`).
  Plurals use explicit singular/plural keys. Dates come from the system formatters in the app's
  language (`Locale` from `Bundle.main.preferredLocalizations`).
- **What isn't translated:** user content, sample data, the Debug menu, the film.
- **Checks:** `scripts/check-strings.sh` builds with `-emit-localized-strings` and fails when a
  key used in the code is missing from any language, or a language has a key the code doesn't
  use. A unit test checks that every language has the same keys as `en` with the same
  placeholders. CI runs both.

## 4. README and website in four languages

- **README:** `README.pt-BR.md`, `README.es.md`, `README.fr.md`, full translations, with a
  language bar at the top of all four.
- **Website:** `site/index.html` stays the English source. Translatable elements carry
  `data-i18n="key"` (inner HTML) or `data-i18n-attr="attr:key;…"`. Translations live in
  `site/i18n/{pt-br,es,fr}.json`. `site/i18n/build.py` (Python standard library only) writes
  `site/<lang>/index.html`: `lang`, canonical, `og:url`, `og:locale`, `hreflang` alternates,
  asset paths, and the demo's strings (`window.STASH_I18N`, used by `demo.js` with English
  fallbacks). `--check` fails on missing or unused keys. The Pages workflow runs it; the
  generated folders are git-ignored.
- **Switcher:** a language menu in the nav. A dismissible banner offers the visitor's browser
  language when it's one of ours; it never redirects.

## 5. Homebrew

- **Tap:** a new public repo `S4MU3LDemolidor/homebrew-tap` with `Casks/stash-references.rb`
  (the official `stash` cask is an unrelated app). Install:
  `brew install --cask s4mu3ldemolidor/tap/stash-references`.
- **Cask:** the release DMG, `sha256`, `depends_on macos: ">= :sonoma"`, `app "Stash.app"`,
  `livecheck` on GitHub releases, `zap` for Application Support and preferences only (never the
  library), and caveats explaining Open Anyway (Stash isn't notarized; the cask doesn't remove
  quarantine).
- **Updates:** a daily workflow in the tap (plus manual run) reads the latest release, downloads
  the DMG, and commits the new version and checksum when they changed.
- **Docs:** README (all languages) and the website show the command with a copy button.
- The tap's files are kept in this repo under `packaging/homebrew-tap/` as the source.
